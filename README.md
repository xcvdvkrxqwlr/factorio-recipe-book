## Overview

Recipe Book adds a searchable in-game encyclopedia to Factorio showing every item's crafting recipe, which machines can produce it, what it can be used to make, and complete production chain visualization from raw resources to finished goods — without needing to alt-tab to the Factorio wiki.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Recipe Book** delivers the features you need in a clean, intuitive package.

> Official website: [mods.factorio.com](https://mods.factorio.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **Recipe Browser** | Search every item and view its complete crafting recipe in-game |
| **Machine Lookup** | See which assemblers, furnaces, and machines can produce each item |
| **Usage Chains** | View every recipe that consumes a given item as an ingredient |
| **Production Trees** | Visualize complete raw-to-finished production chains in one panel |
